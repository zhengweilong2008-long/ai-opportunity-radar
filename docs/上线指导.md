# 上线指导：把 AI 机会雷达发布到 GitHub Pages（零成本）

> 给编程新手的一步一步教程。全程免费，只需要一个 GitHub 账号。

## 准备：注册 GitHub 账号（约 5 分钟）

1. 打开 https://github.com ，点右上角 **Sign up**
2. 输入邮箱、设置密码和用户名，按提示完成邮箱验证
3. 不需要绑定银行卡，不需要买任何东西

## 第一步：创建仓库（约 2 分钟）

1. 登录后点右上角 **+** → **New repository**
2. Repository name 填：`ai-opportunity-radar`
3. 选择 **Public**（公开仓库才能免费使用 Actions + Pages）
4. 不要勾选 "Add a README"，直接点 **Create repository**

## 第二步：上传代码（约 5 分钟）

Muse 会把打包好的项目文件发给你，你：

1. 在仓库页面点 **uploading an existing file**
2. 把 Muse 给你的所有文件拖进去
3. 点 **Commit changes**

> 注意：不要上传 `.venv/`、`data/radar.db`、`site/` 这些本地生成的文件和目录。

## 第三步：开启 GitHub Pages（约 2 分钟）

1. 进仓库 → **Settings** → 左侧 **Pages**
2. Source 选择 **GitHub Actions**（不是 Deploy from a branch）
3. 保存。不需要其他设置。

## 第四步：检查 Actions 权限（约 1 分钟）

1. 进仓库 → **Settings** → 左侧 **Actions** → **General**
2. 确认 "Allow all actions and reusable workflows" 已选中（默认就是）
3. 拉到最下 Workflow permissions，确认是 **Read and write permissions**（工作流文件里已声明，默认即可）

## 第五步：手动触发第一次运行（约 5–10 分钟）

1. 进仓库 → **Actions** → 左侧点 **每日更新**
2. 点右侧 **Run workflow** → **Run workflow**
3. 等待运行完成（绿色 ✅）。点进去可以看到每一步的日志：
   采集 → 评分 → 导出 → 构建 → 测试 → 提交数据 → 发布
4. 完成后访问你的网站：`https://你的用户名.github.io/ai-opportunity-radar/`

## 第六步（可选）：配置 SEC 邮箱和翻译额度

1. 仓库 → **Settings** → **Secrets and variables** → **Actions**
2. **New repository secret** 添加以下（都是可选的，不加也能跑）：
   - `SEC_CONTACT_EMAIL`：你的邮箱。SEC EDGAR 官方要求请求带联系邮箱，
     不配也能跑（用占位邮箱），但建议配。
   - `MYMEMORY_EMAIL`：你的邮箱。翻译额度从 5000 字符/天提到 50000 字符/天，
     无需注册，填邮箱就行。不配的话标题优先翻译，摘要可能翻不完。

## 常见问题

- **定时任务没有准时 08:00 跑？** GitHub 免费版高峰期可能延迟几分钟到几十分钟，
  这是 GitHub 的机制限制，不是配置问题。
- **某天网站没更新？** 去 Actions 看那天的运行日志，红色 ❌ 的步骤会写明原因；
  单个信源失败不影响其他信源，页面会如实显示失败信息。
- **想换仓库名？** 改完后网站地址会变，Muse 会帮你同步修改相关配置。
