# 已实现与未实现功能清单

> 更新时间：2026-10-14（阶段六交付时）

## 已实现 ✅

**阶段一：网站前端**
- [x] 主页（最近更新时间、采集成功率、热点/机会摘要、信源状态表、手动刷新按钮）
- [x] 24H 热点页（Top10，按时间/类别/来源筛选，热度分数+评分依据+置信度）
- [x] 本周机会页（Top5，机会类型/评分/成本区间/变现路径/验证方案/风险/下一步）
- [x] 运行状态页（信源状态、更新记录、通知状态、LLM 用量、日志文件）
- [x] 手机+电脑自适应布局
- [x] 无数据时如实显示"暂无"，无任何模拟数据

**阶段二：数据库与采集**
- [x] SQLite 数据库（UTC 存储、北京时间展示；表：sources/items/runs/daily_reports/llm_usage）
- [x] 十个信源采集器（接口均真实验证）：GitHub Trending / HN / Product Hunt /
      OpenAI / HF Blog / TechCrunch / Reuters（Google News 间接覆盖，标注降级）/
      SEC EDGAR / DeepMind / Google Trends
- [x] URL 去重、原文链接有效性检查、单源失败不影响其他源
- [x] 每次运行记录新增/去重/失败来源/错误原因

**阶段三：去重、摘要、评分**
- [x] 跨信源事件去重（标题相似度聚类，转载不重复计信源）
- [x] 热度评分 100 分制（互动30/时效25/独立信源20/信源可靠15/趋势增长10），
      置信度标注 实际热度/估算热度/数据不足
- [x] 机会评分 100 分制（规则版，保守；中文详情字段措辞谨慎，不承诺收入）
- [x] 投资观察独立评分（SEC 8-K，缺数据标"数据不足"，不做买入推荐）
- [x] 大模型接口（DeepSeek/硅基流动/兼容接口，默认关闭，每日上限+每月预算+自动降级）
- [x] 每日中文摘要（规则版；LLM 开启后由模型生成标题摘要）

**阶段四：定时任务**
- [x] `scripts/daily.py` 每日总入口（采集→评分，日志，退出码）
- [x] `deploy/crontab.txt`（每天 08:00 北京时间）、`deploy/radar-web.service`（systemd）
- [x] cron 最小环境实测通过；`/api/daily-report` 日报接口

**阶段五：通知、日志、状态**
- [x] 邮件/Telegram 通知（默认关闭，失败不中断）
- [x] `scripts/push_report.py` 日报推送脚本
- [x] 运行状态页（含通知/LLM/日志区块）
- [x] 实证结论：外部网站**不能**直接推送到 Muse 聊天（无 inbound API）；
      替代方案为定时任务拉日报接口后投递到聊天（部署后接通）

## 未实现 / 待用户决策 ⏳

- [ ] **Product Hunt Developer Token**：需用户手动申请（免费），填入 `.env` 的
      `PH_TOKEN` 后该信源自动生效；未配置前自动跳过
- [ ] **中文标题摘要的大模型开关**：默认关闭零费用；用户提供 DeepSeek key 后开启
- [ ] **公网部署**：需用户购买云服务器（约 ¥60/月），按 README 教程操作；
      部署后接通每天 08:05 的聊天日报推送定时任务
- [ ] **手动刷新按钮**：后端接口已预留（501），接采集器后启用（部署后可随时做）
- [ ] **趋势增长 10 分**：需积累多日时序数据后启用（当前如实记 0 分）
- [ ] **浏览器视觉截图验证**：开发机与测试浏览器网络隔离，待部署有公网地址后补做

## 明确不做的（合规）

- 不绕过登录/付费墙/验证码/robots.txt（如 Reuters 直接抓取）
- 不使用 pytrends 类逆向接口（违反 Google ToS）
- 不伪造互动数据、发布时间、估值；不把理论盈利写成已验证收入
