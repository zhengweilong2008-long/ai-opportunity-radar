## 可选：大模型（默认关闭）

| 提供商 | 用途 | 费用估算 |
|---|---|---|
| DeepSeek | 中文标题/摘要翻译 | 约 ¥1/百万输入 tokens；本项目每日约 3–5 万 tokens ≈ **¥1–3/月** |
| 硅基流动 | 同上（国内访问快） | 有免费额度；付费约 ¥1/百万 tokens |
| 自定义兼容接口 | 同上 | 按提供商定价 |

保护机制（代码已实现）：
- `LLM_DAILY_CALL_LIMIT`（默认 60 次/天），超限自动降级显示原文
- `MONTHLY_BUDGET_CNY`（默认 ¥20/月），超限自动停用
- 用量与预估费用记在 `llm_usage` 表，状态页可见
- 任何调用失败自动降级，不中断采集评分主流程

## 托管与自动化（全部免费）

| 服务 | 用途 | 费用 | 说明 |
|---|---|---|---|
| GitHub Actions | 每天 08:00 自动采集+评分+构建 | 免费 | 公开仓库无时长限制；定时任务高峰期可能延迟几分钟 |
| GitHub Pages | 托管静态网站 | 免费 | 公开仓库免费；访问地址为 `用户名.github.io/仓库名` |
